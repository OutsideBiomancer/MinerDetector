## 🛡️ About MinerDetector

MinerDetector is a lightweight Windows tool that scans your system for hidden cryptocurrency miners — including silent XMRig-style processes, browser-based miners, and fileless miners injected into legitimate apps.

It checks running processes, CPU/GPU load patterns, network connections, scheduled tasks, autorun entries, and browser extensions to identify suspicious activity. When a miner is found, it can terminate the process, remove persistence, and block its known network endpoints.

The tool is designed for everyday users who noticed high CPU/GPU usage, overheating, or slow performance — and want a fast, clear answer without installing a full antivirus suite.

Everything runs locally, offline, with no telemetry.
